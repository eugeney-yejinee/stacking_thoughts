# FvFlow v12 — 링커가 scFv 의 VH-VL 배향 분포를 바꾸는가, 그게 순도와 이어지는가

```
scFv ─┬─ 링커 뺀 VL / VH 두 서열 ──→ ABodyBuilder2 ──→ 기준점 (이상적 VH-VL 각도)
      │                                                       │
      └─ 링커 포함 한 서열 ──→ BioEmu ──→ 앙상블 ──→ ABangle ──┴─→ Δ(6축) · OCD5/OCD6
                                                                        │
                        합성 링커 요인패널 (조성 7 × 길이 4 + 대조) ─────┤
                                                                        ↓
                                              구성체당 특징 한 줄 → ML → 실측 순도
```

## 묻는 것 셋 — 순서가 있다. 앞이 죽으면 뒤는 읽지 않는다

1. **채널이 있는가.** BioEmu 가 링커 **조성**을 보는가, 아니면 사실상 길이만 보는가.
   → 6절-C(전역) · **6절-D(국소, 결정적)** 가 답한다. 실측 패널로는 원리적으로 못 답한다.
2. **신호가 있는가.** 앙상블 특징이 순도와 이어지는가. → 7절 ① 확증 검정.
3. **길이 말고 다른 게 있는가.** → 7절 ③ **증분 검정.** 이게 진짜 질문이다.

### 고친 것 — 조용히 틀린 값을 내던 것들

각 항목은 오류를 내지 않고 **그럴듯한 숫자**를 돌려주던 것들이다. 그래서 위험했다.

| # | 무엇 | 왜 치명적이었나 |
|---|---|---|
| 1 | **ABangle 검증 CLI** | 상류 `number_sequences` 에 zip 어긋남이 있다. ANARCI 가 한 사슬만 인식하면 다른 사슬의 번호와 짝지어지고, 나머지 사슬은 번호가 안 매겨진다. `write_pair` 가 1..N 으로 빈틈없이 번호를 매기므로 **번호 없는 사슬도 coreset 35개를 그대로 채운다** → Superimposer 성공 → 무의미한 여섯 실수가 나온다. 이제 두 사슬 인식과 H/L 라벨을 직접 확인하고, 덤으로 ANARCI 를 메모이즈해 ABangle 통과를 **412분 → 10~20분**으로 줄였다 |
| 2 | **항체 키 영속화** | 키는 Drive 폴더 이름이다. `groupby().ngroup()` 은 정렬 순서로 번호를 **다시** 매기므로 엑셀에 행이 하나 늘거나 파싱이 조금 바뀌면 모든 번호가 밀리고 v09 출력을 통째로 못 찾는다. `antibody_keys.csv` 에 적어 두고 그걸 정답으로 삼는다 |
| 3 | **`태그` 가 항체 사이에서 유일하지 않다** | `Linker1__BioEmu_s0` 은 블록 5개에 전부 있다. 기하 표를 태그만으로 합치면 블록 1 의 값이 블록 2~5 에도 붙는다. 키를 `(항체, 태그)` 로 바꿨다 |
| 4 | **OCD6 은 사실상 dc 하나다** | dc 의 자연 σ 가 0.268 Å 뿐이라 \|Δdc\| 1 Å 이 OCD6 에 3.7 을 더한다. 나머지 다섯 축은 2~3 을 넘는 일이 드물다. 게다가 짝지음 게이트가 **바로 그 dc** 로 프레임을 거른다 — 결과의 성분으로 표본을 고른 셈이라, 많이 열린 링커일수록 남은 프레임의 OCD6 가 *낮게* 보인다. 각도 주지표를 **OCD5(dc 제외)** 로 바꾸고, 짝지음은 **절대 dc** (SAbDab 평균 16.206 Å ± 6σ) 로 판정한다. 원시 6값도 저장해 나중에 정의를 바꿔도 ABangle 을 다시 안 돌린다 |
| 5 | **실측 열이 분석 직전에 버려졌다** | 로더는 8개 키워드로 찾고, 합성 행 비우기는 3개로 비우고, 분석은 `hmw` 하나만 집어 갔다. Monomer·Titer·SEC·순도가 표에 찍히고 나서 사라졌다 — 재려던 "순도" 가 분석에 도달한 적이 없다. `OBS` 를 **한 곳에서** 정의해 전부 공유한다 |
| 6 | **합성 구성체가 숙주의 실측값을 물고 갔다** | 숙주 행을 복사해 만드는데 비우기 키워드가 로더와 달랐다. 지어낸 서열 3~24개가 **같은 y 값을 가진 진짜 데이터점**으로 상관에 들어갔다. 이제 `OBS` 전부를 비우고 단언으로 막는다 |
| 7 | **독립 단위가 블록이 아니라 항체다** | 한 블록에 항체가 둘 이상 들어갈 수 있고 (LH/HL 두 배향), 항체마다 ABB2 기준점이 **따로** 잡힌다 = Δ 의 영점이 다르다. 블록으로 묶으면 '링커 간 차이' 항이 '항체 간 차이' 를 빨아들인다 |

| 9 | **빈 도메인 칸이 링커 색인을 밀었다** | `Domain_2` 가 비면 `Domain_1`+`Domain_3` 이 `Linker_1` 과 짝지어졌다. 원래 열 위치로 들고 이웃 쌍만 짝짓는다 |
| 10 | **빈 블록 칸이 `groupby` 에서 조용히 빠졌다** | `fillna(1)` + 문자열 정규화 + 단언 |

## ML 설계 — 왜 이 모양인가

데이터가 이렇게 생겼다.

```
구성체 26개 · 링커 3종 이상인 항체 5개 · 독립 단위는 구성체가 아니라 항체 5개
항체끼리 기준점도 정제 공정도 달라 절대값 비교 불가
항체 안에서 링커 길이와 조성이 완전히 얽힘
특징 하나하나가 150 프레임의 통계량이라 자체 오차가 있음
```

그래서 딥러닝이 아니라 **올바른 검정** 넷이 필요하다.

1. **타깃** — 항체 안에서 중심화한 로짓. `y_ij = logit(p_ij) − mean_j(logit(p_·j))`.
   계량경제의 within-transformation = 항체 고정효과와 정확히 같다.
2. **검증** — Leave-One-Group-Out. **표준화도 학습 폴드 안에서만** 적합한다.
3. **지표** — 항체 안 쌍 일치도. 링커 4종이면 Spearman 이 `{±1, ±0.8, ±0.4, ±0.2, 0}`
   밖에 못 내지만, 항체 안 쌍을 모으면 5×6 = 30쌍이 되고 이항분포 해석이 붙는다.
4. **유의성** — 순열 검정 둘.
   - **귀무 A (신호)**: 항체 안에서 `y` 를 섞는다.
   - **귀무 B (증분)**: `y` 는 그대로, **앙상블 특징 행만** 항체 안에서 섞는다.
     → "앙상블은 **길이 위에** 아무것도 더하지 않는다". **이게 진짜 질문이다.**

그리고 **검정력 곡선**. 라벨을 알려진 효과크기로 심어 진짜 분석을 통째로 다시 돌린다.
β=0 행이 거짓양성률이다. 자체 시험에서 관측된 값: **거짓양성률 0.03~0.04**(명목 0.05,
이산성 때문에 약간 보수적), **검출률 80% 에 닿는 최소 효과 β ≈ 0.9~1.3**.
즉 특징 1 표준편차가 타깃을 1 σ 가까이 움직여야 보인다. 작지 않은 효과다.

**이 곡선이 없으면 "상관이 없었다" 는 아무 뜻도 없다.**

## 이 파이프라인이 증명할 수 없는 것 — 미리 적어 둔다

1. **응집은 모델 밖이다.** BioEmu 는 *single protein chains* 를 emulate 하고 올리고머
   상태는 암묵적이다 (Lewis et al., *Science* **389**, eadv9817 (2025), Discussion).
   우리가 재는 것은 **단량체 앙상블의 열린 정도**이고 HMW 는 **이량체 형성의 결과**다.
   그 사이의 연결은 모델이 아니라 **가설**이다. 상관이 나와도 그 가설의 증명은 아니다.
2. **인공 링커는 논문이 검증한 범위 밖이다.** 성능이 서열유사도 30% 에서 평탄해지는데
   그건 **천연 단백질** 기준이고 `(G4S)ₙ` 에는 진화 정보가 없다.
   다만 **반대 증거도 있다** — PPFT 는 점돌연변이 50만 건으로 학습했고 ΔΔG Spearman > 0.6,
   Fig 4F 는 단일 치환이 국소 헬릭스 함량을 바꾸는 것을 보인다. 한 잔기가 모델에 닿는다.
   그래서 이건 **양면 가설**이고, 6절-C·6절-D 가 직접 재는 유일한 장치다.
3. **150 프레임은 논문 기준의 1.5% 다.** 본문 결과는 전부 10,000 샘플로 냈다.
   분포의 **꼬리**(= 열림분율이 사는 곳)가 그만큼 덜 수렴했다.
4. **독립 단위는 26 이 아니라 5 다.** 합성 데이터를 아무리 만들어도 이 숫자는 안 는다.
5. **A∘B 스크리닝은 검증이 아니다.** 후보를 정렬해 줄 뿐이고, 상위 후보는
   **실제로 만들어 재봐야** 한다.
